# Deployment

Bespoken TTS is a standard Laravel app — it runs anywhere Laravel runs. The only
extras beyond a normal Laravel deploy are **ffmpeg** (audio normalization +
format conversion) and a one-time **Node build** of the dashboard assets.

## Requirements

- PHP **8.3+** with the usual Laravel extensions
- Composer
- A database — MySQL/MariaDB recommended in production (SQLite also works)
- **ffmpeg** on the server
- **Node 20+** and npm (to build the dashboard)
- A **Replicate API token** for real generation (or run with `TTS_PROVIDER=fake`)

## Laravel Forge

### 1. Create the site
On **Install a Laravel application**:

- **Repository:** `johnfmorton/bespoken-tts-service` · **Branch:** `main`
- **Connect to database:** on → **Create a new database** (Forge injects `DB_*`)
- **Install Composer dependencies:** on
- **Generate a site deploy key:** off — your connected GitHub account owns the
  repo. If the install can't clone the private repo, enable this, add the shown
  key to the repo's *Settings → Deploy keys*, and retry.
- **Advanced settings → PHP version:** 8.3+. Leave the web directory as `/public`.

### 2. Install ffmpeg (one time)
Via SSH or Forge's command runner:
```bash
sudo apt-get update && sudo apt-get install -y ffmpeg
ffmpeg -version    # confirm
```

### 3. Configure the environment
Edit the site's **Environment** in Forge:
```env
APP_ENV=production
APP_DEBUG=false
APP_URL=https://your-domain.com        # match the site's domain

# DB_* are injected by Forge

TTS_PROVIDER=replicate
REPLICATE_API_TOKEN=r8_xxx             # required for real generation
TTS_STORAGE_DISK=local                 # or s3 (+ AWS_* credentials)

# Dashboard admin (used once to create the login)
ADMIN_EMAIL=you@example.com
ADMIN_PASSWORD=a-strong-password
```
`APP_KEY` is generated by Forge during install. The Chatterbox model + pinned
version ship as config defaults, so you only need the token.

### 4. Deploy script
The deploy script must **build the dashboard assets** (`npm run build`) and run
migrations.

**Forge's zero-downtime (atomic releases) default already does both** and needs
**no changes** for this app:

```bash
$CREATE_RELEASE()

cd $FORGE_RELEASE_DIRECTORY

$FORGE_COMPOSER install --no-dev --no-interaction --prefer-dist --optimize-autoloader

npm ci || npm install
npm run build
$FORGE_PHP artisan optimize
$FORGE_PHP artisan storage:link
$FORGE_PHP artisan migrate --force

$ACTIVATE_RELEASE()

$RESTART_QUEUES()
```

Two things to know with this script:

- It runs `artisan optimize`, which **caches config** — so `env()` reads outside
  config files (the `AdminSeeder`) won't resolve. Create the admin with
  `admin:create` (next step), not the env seeder. The Replicate token is read
  into cached config at deploy time, so generation is unaffected. (All routes are
  controller/view-based, so `route:cache` inside `optimize` is safe.)
- With atomic releases, ensure **`storage` is one of the site's linked/shared
  directories** (Forge's default) so uploaded voice clips and generated audio in
  `storage/app/private` persist across deploys. `.env` is already shared by Forge.
  `storage:link` is harmless here — this service serves audio through the app, not
  `public/storage`.

If you're instead on the **older, non-atomic** deploy script, add the two `npm`
lines after `composer install` and make sure `php artisan migrate --force` runs.

### 5. Deploy, then create the admin
- Click **Deploy Now** (runs composer, builds assets, migrates).
- Create the dashboard login once (command runner / SSH):
  ```bash
  php artisan admin:create you@example.com
  ```
  (or, if `ADMIN_EMAIL`/`ADMIN_PASSWORD` are set **and** config is not cached,
  `php artisan db:seed --class=AdminSeeder --force`).

### 6. SSL + timeouts
- Enable **Let's Encrypt** SSL for the domain.
- A first (cold) generation can take up to ~60s. Raise timeouts so the request
  isn't cut off (Forge site settings):
  - nginx: `fastcgi_read_timeout 120;`
  - PHP: `max_execution_time = 120`

### 7. First use
Visit `https://your-domain.com/`, log in, then:
- **API Keys → New key** (copy it).
- **Voices → Add voice** (upload a clean ~15–30s clip).
- The **Dashboard** shows copy-paste connection details for the Bespoken plugin.

## Notes

- **Config caching:** Forge's default deploy runs `artisan optimize`, which caches
  config and skips loading `.env` at runtime — so `env()`-based code (the
  `AdminSeeder`) won't see values. Create the admin with `admin:create`
  (argument-based). The Replicate token is read into cached config at deploy time,
  so generation is unaffected.
- **Storage durability:** with `TTS_STORAGE_DISK=local`, voice references and
  generated audio live in `storage/app/private` on the server (persists across
  deploys). Use `s3` if you re-provision servers or run more than one instance.
- **No queue or scheduler is required** in this release — generation is synchronous.

## Generic (non-Forge) install

The same steps by hand on any host:
```bash
git clone https://github.com/johnfmorton/bespoken-tts-service.git
cd bespoken-tts-service
composer install --no-dev --optimize-autoloader
cp .env.example .env && php artisan key:generate
# edit .env: APP_URL, DB_*, TTS_PROVIDER, REPLICATE_API_TOKEN, ADMIN_*
php artisan migrate --force
php artisan admin:create you@example.com
npm ci && npm run build
sudo apt-get install -y ffmpeg
```
Point your web server's document root at `public/`.
